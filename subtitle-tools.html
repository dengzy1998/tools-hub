About these subtitle tools

Different platforms want different subtitle formats: YouTube accepts both, most HTML5 players need WebVTT (.vtt), and editing software and older players expect SubRip (.srt). The only real differences are the header, the decimal separator in timestamps and cue numbering — this converter handles all of it, including VTT cue identifiers and SRT files with sloppy formatting.

The time shift fixes the classic "subtitles run half a second late" problem: measure the offset once, enter it in milliseconds (negative values move subtitles earlier) and apply. Fix & renumber sorts cues by start time, renumbers them cleanly and normalizes every timestamp to the strict format players expect, which rescues many files that refuse to load.
