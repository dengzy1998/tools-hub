How to use this QR code generator

Type or paste a link, text, phone number or any short message, choose a size, and click Generate. Your QR code is created right in your browser and can be downloaded as a PNG image — ready for posters, menus, packaging, business cards or sharing in chat.

For print, pick the 1024 × 1024 size so the code stays sharp. Keep the content short: the more text a QR code holds, the denser it becomes and the harder it is to scan. A short URL works best. The code uses a high error-correction level, so it still scans even if a small part is covered or smudged.
